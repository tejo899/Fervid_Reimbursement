Fervid Claims — iOS Web App (PWA)
===================================

This folder contains the iPhone/iPad-ready web version of Fervid Claims, converted from your Android APK.

How to deploy (free, takes ~2 minutes):
1. Unzip this folder.
2. Upload the folder to any HTTPS static host, such as:
   - Netlify Drop (https://app.netlify.com/drop) — drag and drop the folder to get an instant HTTPS URL.
   - GitHub Pages, Vercel, Cloudflare Pages, or your company's internal web server.
   (Note: iOS Safari requires HTTPS for "Add to Home Screen" and offline Service Worker caching.)

How to install on iPhone / iPad:
1. Open the hosted URL in Safari on your iPhone.
2. Tap the Share button (square with upward arrow) at the bottom of Safari.
3. Scroll down and tap "Add to Home Screen", then tap "Add".
4. Launch "Fervid Claims" from your Home Screen. It will run full-screen and work offline.
